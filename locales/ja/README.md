# OneToEight Agent：概要とセットアップの手順

**OneToEight Agent** は、[Hermes Agent](https://hermes-agent.nousresearch.com/docs)
を土台にした、自分に合わせて動くAIアシスタントです。**8つの
エッセンシャル**を日々の生活に取り入れながら学ぶ若い世代のために
作られました。やさしいメンターとして、音声のプラン、ふり返りの
チェックイン、小さな行動という毎日のリズムを回していきます。
教える内容は、リポジトリに同梱されている8つのエッセンシャルの
ガイドから取り出します。

この README は、エージェントを最初から最後まで動かせるようにする
ための概要と手順です。まず一度読んでから、ステップを順番に進めて
ください。

> **入り方は2つ。** **build path** を歩んで、エージェントを一つずつ
> 組み上げていくやり方があります。毎週、1つの能力と1つの見える成果を、
> 音声を追いながら。もう1つは、下のセットアップの手順でインストール
> するやり方です。
>
> **build path をはじめる：<https://gladtobe.here.now/build-path/>**

> 他の言語で読む: **日本語** · [English](README.md) · [Bahasa Melayu](README.ms.md) · [ไทย](README.th.md) · [Tiếng Việt](README.vi.md) · [Filipino](README.tl.md) · [Bahasa Indonesia](README.id.md) · [Español](README.es.md) · [中文](README.zh.md) · [한국어](README.ko.md)

## このプロダクトについて

若い世代にとって、8つのエッセンシャルが一番よく身につくのは、本を
読むことではなく、何週間、何か月もかけて**毎日1つ、小さなことを
やってみる**ことです。OneToEight Agent は、その毎日のリズムを
根づかせるためにあります：

- **朝の1分**（Morning Minute）が、選んだ時刻に学ぶ人のチャット
  （Telegram か WhatsApp）に届きます。その日のための短い音声プランと、
  テキストです。
- **午後のチェックイン**（Afternoon Check-In）が、午後に届きます。
  短いテキストメッセージです。今日がどうだったか、次に何があるか、
  夜のあいだ持ち歩く問いが1つ。
- **プランニングセッション**（Planning Session）が、寝る前に届きます。
  明日の輪郭を描きます。学校の課題、宿題の締め切り、今週取り組んで
  いるエッセンシャル、実生活でやってみたいこと1つ。下書きをするのは
  エージェント、編集するのは学ぶ人で、内容はローカルに保存されます。
  アプリも、アカウントも、クラウド同期もありません。
- エージェントは、リポジトリに入っている**8つのエッセンシャルの
  ガイド**（`essentials/01..08/lessons/*.md`）から教えます。教え方は、
  学ぶ人が選んだ伝統によって枝分かれします。
- ガイドは**10の言語**でも公開されています。オンラインで読むか、
  インターネットなしで使えるオフラインパックとしてダウンロードして
  ください。`essentials/guide-editions.md` を見てください。

エージェントは説教しません。問いかけで学ぶ人の中から知恵を引き出し、
リズムをやさしく保ち、途切れてしまったときには、叱らずに、また
始められるように支えます。

### 2つの伝統、または自分だけの伝統

学ぶ人は、オンボーディングでどちらかを選びます。自分が属している
伝統をエージェントに伝えれば、それを組み込んでくれます。エージェントは
選ばれた伝統の中にとどまり、伝統を混ぜることはありません：

- **キリスト教**：聖書を土台にします。朝の1分には毎朝、聖書の一節が
  自然に読み上げられます。チェックインは、生きた信仰の中で一日を
  位置づけます。
- **ユニバーサル（世俗）**：教義を持ち込まず、知恵の伝統を大切に
  します。朝の1分には、ある思想家の短いふり返りや問いが入ります。
  チェックインは、ふり返りと感謝、これからの意図の中で一日を
  位置づけます。

伝統はあとから変えられますが、レッスンはその時点から枝分かれします。

### 2つの提供順

学ぶ人は、8つのエッセンシャルをどの順番で受け取るかも選びます：

- **順番どおり**（デフォルト）：エッセンシャル1から8へ、順に進みます。
  これが一番まとまりがあり、ガイドが書かれたときの順番です。
  はじめて学ぶ人におすすめです。
- **ランダム**：その日に必要そうなエッセンシャルを引きます（一番間が
  空いたもの、最近つまずいたもの、その日の元気）。朝の1分は、選ばれた
  エッセンシャルの知識のまとめと、小さな活動1つで始まります。
  もう自分に何が必要かを分かっている人に向いています。

どちらのモードでも、**遅かれ早かれ8つすべてを扱います。** あとから
切り替えたいときは、`essentials_order` メモリーキーを更新するだけです。
オンボーディングをやり直す必要はありません。

### 8つのエッセンシャル（ガイドが教える順番）

1. **静けさに座る力**：じっとして、自分の考えとだけ一緒に過ごすこと
2. **体という家**：睡眠、食べもの、水、体を動かすこと、日光
3. **実生活に役立つ技能**：暮らしに役立つ本物の力（料理、修理、ものづくり、お金のやりくり）
4. **デジタル自衛**：プライバシー、注意力、身元を守る力
5. **本物のコミュニティ**：自分の名前を知っている人たち
6. **持ち運べる知識**：借りるのではなく、自分のものにする
7. **外のための場所をつくる**：外で過ごす時間は、決めごととして確保する。譲れない
8. **信じていることを試す**：自分の信念。プレッシャーの下でも揺るがない

## 動くしくみ

### 1日のループ

```
06:00  朝の1分              Piper の音声 + テキスト → Telegram か WhatsApp
        ↓
日中   学ぶ人が小さな行動を1つ行う
        ↓
17:00  午後のチェックイン    テキストのみ → Telegram か WhatsApp
        ↓
21:00  プランニングセッション テキストのみ → Telegram か WhatsApp
       エージェントが明日のプランを下書き → 学ぶ人が編集 → ローカルに保存
        ↓
        睡眠
        ↓
        繰り返し
```

エージェントは、くどく言わずにループを支えます。抜けてしまった日は、
そっと再開します。叱りません。説教もしません。

**スケジュールについて：** 上の時刻は、学ぶ人のローカルタイムゾーン
でのものです。cron デーモンはスケジュールを **UTC** で保存します。
たとえば日本時間の朝6時（UTC+9）を選ぶと、cron には `0 21 * * *`
（21:00 UTC）と保存されます。スケジュールはいつも「自分のタイムゾーン
での時刻」で、UTC への変換は自動です。

### それぞれの場面でエージェントがすること

| 場面 | エージェント |
|---|---|
| 新しいプロファイルでの最初のチャット | エージェント自身の声で、手短にオリエンテーションを提案します |
| 学ぶ人が「セットアップして」と言ったとき | `agent-onboarding` を実行します（同意を確かめながら、段階的に） |
| 学ぶ人が質問したとき | 関係する `essentials/<NN-name>/lessons/*.md` を読み、まとめてから教えます |
| 朝の1分の cron が起動したとき | その日のプランを作り、Piper を動かし、アップロードして、直接届けます |
| チェックインの cron が起動したとき | 直近の朝の1分を読み、短いふり返りを書き、テキストとして届けます |
| プランニングセッションの cron が起動したとき | 明日のプラン（学校の課題、締め切り、今週のエッセンシャル、実生活でやること1つ）を下書きします。編集するのは学ぶ人で、ローカルに保存されます |
| 学ぶ人がもっと深く学びたいと言ったとき | `eight-essentials-curriculum` スキルを使います。ガイドを読み、そこから教えます |

### バックグラウンドで動くもの

3つの cron ジョブです。どれも、学ぶ人がオンボーディングで承認する
までは止まっています：

1. **朝の1分**：学ぶ人のタイムゾーンで選んだ時刻に起動します。毎日
   （希望すれば平日のみ）。音声 + テキストを作り、Telegram か
   WhatsApp に届けます。
2. **午後のチェックイン**：選んだ午後の時刻に起動します。日のルールは
   朝の1分と同じです。短いテキストメッセージを送ります。
3. **プランニングセッション**：寝る前（デフォルトは夜9時）に起動
   します。日のルールは同じです。明日のプランを下書きして、学ぶ人が
   編集できるようにし、それからローカルに保存します。

3つとも**オプトイン**です。オリエンテーションが作るのは、はっきり
した同意があったときだけです。

### 毎日の20のプロンプト

若い世代がいつでも OneToEight Agent に投げかけられる、とっておきの
問いの小さなコレクションです。エージェントは関係するガイドの章を
読み、学ぶ人についてすでに知っていることを踏まえて、その人の声で、
その人の伝統に沿って答えます。

大事なのは、20個すべてに毎日答えることでは**ありません**。エッセンシャル
を浮かび上がらせ、ふり返りを引き出し、好奇心を毎日の実践に変えていく、
とっておきの問いを少しだけ持っておくことです。1つか2つを選んでください。
残りは飛ばしてかまいません。1週間の中で回していきましょう。

プロンプトは、若い世代の声で書かれています。エージェントは説教を
返しません。問いを投げかけ、答えのための余白を保ち、小さな行動を
1つ添えて返します。

プロンプトの全文は
`essentials/00-introduction/lessons/prompts.md` にあります。学ぶ人が
「何か考えたい」「持ち歩く問いがほしい」「行き詰まったので助けて」と
言ったときに、エージェントがこれを読みます。

#### 重ためのプロンプト（使うのはめったに）

**#1**、**#5**、**#10**、**#18** のプロンプトは重ためです。エージェント
からは決して勧めません。学ぶ人が自分から名前を出して頼むものです。
重ためのプロンプトを頼まれて、エージェントが「今日ではない」と
判断したときは、やさしく軽めの代わりを提案して、理由を説明すること
があります。

#### エージェントはこれをどう使うか

エージェントは、学ぶ人がプロンプトを求めたときに
`essentials/00-introduction/lessons/prompts.md` を読みます。プロンプトを
学ぶ人に**貼りつける**ことはしません。1つを取り上げ、読んでみるよう
誘い、答えのための余白を保ちます。3つ続けて問いかけることはありません。

**順番どおり**の提供では、プロンプトは自然に、学ぶ人が取り組んで
いるエッセンシャルのまわりに集まります。**ランダム**のときは、
エージェントがその瞬間に合うプロンプトを選びます。どちらのモードでも、
8つすべてはいつでも使えます。

## 毎日のリズム

エージェントが動かすすべてのリズムを、ひと目で分かるようにした地図
です。何なのか、いつ動くのか、どこに届くのか、詳しくはどこに書いて
あるのか。

| リズム | いつ | チャンネル | 起きること |
|---|---|---|---|
| **朝の1分** | 毎日、学ぶ人が選んだ時刻（デフォルトは朝6時） | Telegram か WhatsApp。**音声メッセージ + テキスト** | その日の音声プラン。今取り組んでいるエッセンシャルから、小さな行動1つに絞ります。 |
| **午後のチェックイン** | 毎日、学ぶ人が選んだ時刻（デフォルトは午後5時） | Telegram か WhatsApp。**テキストのみ** | 今日がどうだったかのふり返り、明日のプラン、夜のあいだ持ち歩く問いが1つ。 |
| **プランニングセッション** | 毎日、寝る前に、学ぶ人が選んだ時刻（デフォルトは夜9時） | Telegram か WhatsApp。**テキストのみ** | エージェントが明日のプラン（学校の課題、宿題の締め切り、今週のエッセンシャル、実生活でやること1つ）を下書きします。編集するのは学ぶ人です。ローカルに保存されます。 |
| **エッセンシャル要約** | 学ぶ人が求めたときに、いつでも | Telegram か WhatsApp。**音声メッセージ** | エッセンシャル1つの3〜5分の読み上げ要約 + 短い要点リスト。 |
| **エッセンシャルレッスン** | 学ぶ人が求めたときに、いつでも | here.now。**チャットに届く HTML ページのリンク** | エッセンシャル1つの3ページのレッスン。引用元を示した資料、重要な引用、短いクイズつき。 |
| **エッセンシャルポエム** | 学ぶ人が求めたときに、いつでも | Telegram か WhatsApp。**音声メッセージ + テキスト** | エッセンシャルについての、韻を踏んだ朗読詩。読み上げと一緒に、テキストも届きます。 |
| **エッセンシャルソング** | 学ぶ人が求めたときに、いつでも | Telegram か WhatsApp。**MP3 の音声メッセージ + テキスト** | エージェントがエッセンシャルについての詩を書き、OpenRouter の Google Lyria 3 で本物の歌にします。1曲あたり約 $0.08。実行の前に費用を確認してください。 |
| **エッセンシャルミュージックビデオ** | 学ぶ人が求めたときに、いつでも | here.now。**チャットに届く MP4 動画のリンク** | 上の歌に、音声と組み合わせた静止画の絵コンテを加えたもの。詩のテキストを重ねることもできます。全部で約 $0.35。実行の前に費用を確認してください。 |

**一日の流れ。** 朝の1分が一日を開き、チェックインが閉じ、プランニング
セッションが寝る前に明日の輪郭を描きます。3つのオンデマンド形式
（要約 / レッスン / ポエム）は、朝の1分が1分で触れられるより深く
エッセンシャルを学びたいときに、いつでもどうぞ。

**コードのありか。** それぞれの行が、リポジトリ内のスキルに対応して
います：

| リズム | スキルのパス |
|---|---|
| 朝の1分 | `skills/hermes/morning-minute/` |
| 午後のチェックイン | `skills/profile/afternoon-checkin/` |
| プランニングセッション | `skills/profile/planning-session/` |
| エッセンシャル要約、レッスン、ポエム、ソング、ミュージックビデオ | `skills/profile/essential-deep-dives/`（ソングとミュージックビデオは `skills/creative/openrouter-lyria-music/` と `skills/creative/poem-song-video-studio/` を使います） |

**同意。** cron で動く3つのリズム（朝の1分、チェックイン、プランニング
セッション）は、オンボーディングで学ぶ人か保護者が承認するまで止まって
います。5つのオンデマンド形式（要約、レッスン、ポエム、ソング、
ミュージックビデオ）はすぐに使えます。学ぶ人が頼むだけです。有料の
2つの形式（ソングとミュージックビデオ、Lyria 3 + 絵コンテ画像）は、
頼まれるたびに、学ぶ人の費用の確認が必要です。正確なオプトインの流れは、
[セットアップの手順 → バックグラウンドで動くもの](#バックグラウンドで動くもの)
を見てください。

**ソングとミュージックビデオのスキル。** 有料の2つの形式は、新しい
ものを作らず、すでにある2つのスキルを使い回します：

| 形式 | 土台のスキル | `essential-deep-dives` に足すもの |
|---|---|---|
| **エッセンシャルソング** | `skills/creative/openrouter-lyria-music/` | 詩の歌詞 → Google Lyria 3 で MP3 音声（1曲 約 $0.08）。 |
| **エッセンシャルミュージックビデオ** | `skills/creative/poem-song-video-studio/` | 歌 + 約8枚の絵コンテ画像 + ffmpeg → MP4（全部で約 $0.35）。 |

どちらのスキルも、Lyria 3 の詳細なモデルメモ、スクリプト、コストガード
つきで、すでにリポジトリにあります。学ぶ人がその形式を頼むと、
エージェントが土台のスキルを読み込みます。

**カスタマイズのしかた。** セットアップのとき、エージェントが、cron の
リズムごとに時刻、タイムゾーン、日のルールを選ぶのを手伝います。
3つとも、あとから `cronjob(action="...")` で一時停止、再開、削除できます。
オンデマンドの形式は、学ぶ人の伝統を自動で選びます。声と長さは、
すでに選んである朝の1分の Piper の声を受け継ぎます。

## セットアップの手順

### 1：最初に必要なもの（最初の一度だけ、パソコンで）

必要なもの：

- **Hermes Agent** がインストールされていること。すぐ確認するには `hermes --version`。[インストールガイド](https://hermes-agent.nousresearch.com/docs) を見てください。
- **Python 3.10 から 3.13**（Windows ストアの簡易版ではなく、本物のインストール）。`python --version`。
- **Piper TTS**：ちゃんと動くインストール。下のステップ2を見てください。
- **ffmpeg**：WAV → OGG 変換のため。`ffmpeg -version`。
- **モデルプロバイダーのキー。** プロファイルのデフォルトは `openrouter + deepseek-v4-flash` です。キー1つで、大きなモデルのカタログが使えます。無料枠のモデルや、マルチモーダル（画像、音声）のモデルも含みます。<https://openrouter.ai/> で無料登録して、`hermes setup` でキーを追加してください。代替は OpenCode Go です。
- **Jina AI の無料 API キー**：ウェブ検索のため。<https://jina.ai/> で無料登録できます。クレジットカードは不要です。無料枠で、若い世代の毎日の利用には十分です。
- **Telegram の bot**（おすすめ）、または WhatsApp ブリッジ。Telegram のほうがずっと簡単です。ステップ4を見てください。

### 2：プロファイルを展開する（最初の一度だけ）

プロファイルは zip ファイル `onetoeight-agent-ja.zip` として手に入ります。
これを `~/.hermes/profiles/` の中で解凍して
`~/.hermes/profiles/onetoeight-agent/` にしたら、次を実行します：

```bash
mkdir -p ~/.hermes/profiles
# onetoeight-agent-ja.zip をこのフォルダに解凍してください
hermes profile use onetoeight-agent
hermes chat
```

> **メモ：** プロファイルのディレクトリ名は `onetoeight-agent` で、
> `onetoeight` ではありません。プロファイルのパスに触れるコマンドは、
> それに合わせて更新してください。

あとで更新するときは：新しい zip をダウンロードして、一時的なフォルダに
解凍します。新しいファイルをコピーして入れ替えますが、`memories/`
フォルダと、これまでに記録されたセッションは**消さないでください**。
フォルダのいちばん上にある `LOCALE.md` に、どの版から来たものであるかが
記録されています。

### 3：最初のチャット → オリエンテーション

最初のチャットで、エージェントはこう切り出します：

> 「はじめる前に、セットアップを案内しましょうか？ 2、3分で終わって、
> 道具とメモリー、朝の1分が、好みの形で動くようになります。飛ばして、
> そのまま始めることもできますよ。」

はいと答えてください（または、いつでも *「プロファイルのセットアップを
手伝って」* と頼んでください）。`agent-onboarding` スキルが動きます。

### 4：オリエンテーション（同意を確かめながら）

オリエンテーションは会話形式です。エージェントは、関係する質問を
小さなまとまりごとに1つずつ尋ね、**認証情報の関門では必ずいったん
止まります**。チャットの中でキーやトークンを求めることはありません。

扱う内容を、順番に並べます：

| ステップ | 起きること | どこに追加するか |
|---|---|---|
| 1. アイデンティティ | 名前（自分の、学ぶ人の、エージェントの）、返信のスタイル、ガイド・レッスン・メッセージに使う言語 | プロファイルのメモリーに保存 |
| 2. プロファイルと生活 | 年齢、場所、暮らしの状況、1週間の形、興味3つ、フォーカスの目標、友だちの輪、つまずき、触れてほしくないこと。エージェントが朝の1分とレッスンを合わせるために使う項目です | プロファイルのメモリーに保存 |
| 3. 伝統 | キリスト教、ユニバーサル、または自分だけの伝統 | プロファイルのメモリーに保存 |
| 4. Piper のインストール + 声 | Piper が動くことを確認し、声を選び、音声モデルをダウンロードします | 音声モデルは `piper-voices/` に |
| 5. Jina API key | 無料登録して `.env` に追加すると、エージェントが実際の検索で確認します | `.env` の `JINA_API_KEY=` |
| 6. 配信チャンネル | Telegram か WhatsApp の bot の認証情報 | `.env` の `TELEGRAM_BOT_TOKEN=` / `WHATSAPP_*` |
| 7. 8つのエッセンシャルのガイド | レッスンの MD ファイルが `essentials/01..08/lessons/` にあることを確認し、学ぶ人の言語のガイド版を共有します（`essentials/guide-editions.md`） | リポジトリ内のファイル |
| 8. メモリー | Mnemosyne がおすすめ（ローカル優先、外部アカウント不要） | `hermes memory setup` |
| 9. 朝の1分のスケジュール | 何時、どのタイムゾーン、どの曜日 | cron ジョブとして作成 |
| 10. 午後のチェックインのスケジュール | 何時、どのタイムゾーン、どの曜日 | cron ジョブとして作成 |
| 11. プランニングセッションのスケジュール | 何時（デフォルトは夜9時）、どのタイムゾーン、どの曜日 | cron ジョブとして作成 |
| 12. Token Router（任意） | ツールの範囲を絞るプラグイン | `config.yaml` の `plugins.enabled` |

最後に、エージェントが**提案するセットアップ**のまとめを見せて、
何かを適用する前に、はっきりした承認を待ちます。

echo "The Morning Minute is ready." | piper -m piper-voices/en/en_US/joe/medium/en_US-joe-medium.onnx -f /tmp/piper-test.wav

### 6：最初の定時実行

朝の1分は、学ぶ人のタイムゾーンで、次に予定された時刻に起動します。
音声（Piper）を生成し、公開 URL のために here.now にアップロードし、
その音声を multipart upload で直接 Telegram に届けます。
`MEDIA:<url>` のリンクでは**ありません**（here.now の Cloudflare 設定が、
Telegram のファイル取得 bot をブロックするためです）。チェックインは、
次に予定された午後の時刻に起動します。

### 7：日々の使い方

学ぶ人は、毎日ターミナルの中でエージェントとやり取りするわけでは
ありません。Telegram か WhatsApp のチャットが、毎日の**窓口**です：

- **朝の1分**は、音声メッセージ + テキストのプランとして届きます。
- **午後のチェックイン**は、テキストとして届きます。
- **プランニングセッション**は、寝る前にテキストとして届きます。エージェントが明日のプラン（学校の課題、宿題の締め切り、今週のエッセンシャル、実生活でやること1つ）を下書きし、編集するのは学ぶ人で、ローカルに保存されます。`skills/profile/planning-session/` を見てください。
- **チェックインに返信**して、今日がどうだったかを一行で書きましょう。エージェントがそれをまとめて保存し、明日の朝の1分の呼び水として使います。
- **いつでも質問できます。** 「信念が試されるとき、実際はどんな感じなの？」「本物のコミュニティはどうやって見つけるの？」エージェントはガイドを読んで教えます。

#### エッセンシャルをもっと深く学ぶ（オンデマンド）

毎日のリズムに加えて、学ぶ人は、どのエッセンシャルについても**3つの
深い形式**を求められます。3つとも `essential-deep-dives` スキルが
担当し（`skills/profile/essential-deep-dives/` を見てください）、
頼むだけで使えます：

- **エッセンシャル要約**：エッセンシャル1つの要点を、平易な言葉で。
  さらに、エージェントが作った（Piper）3〜5分の**音声メッセージ**が
  チャットに届くので、散歩しながらでも、家のことをしながらでも
  聞けます。
- **エッセンシャルレッスン**：美しい**3ページのレッスン**。HTML
  ページとして作られ、家庭の **here.now** アカウントに公開されます。
  エッセンシャルを、**引用元を示した資料**（ガイドに載っていない
  内容が必要なときは、Jina API で調べます）、**重要な引用**、そして
  ページ上で答えられる短い**クイズ**で教えます。エージェントがチャットで
  リンクを送ります。
- **エッセンシャルポエム**：エッセンシャルについての、韻を踏んだ
  **朗読詩**。音声メッセージとして読み上げられ、下にテキストが付く
  ので、読みながら聞けます。
- **エッセンシャルソング**：エージェントがエッセンシャルについての
  オリジナルの詩を書き、OpenRouter の `google/lyria-3-pro-preview` で
  本物の歌（MP3）にします（1曲 約 $0.08）。チャットで音声メッセージが
  流れ、詩のテキストが続きます。実行の前に費用を確認してください。
- **エッセンシャルミュージックビデオ**：上の歌に、音声と組み合わせた
  画像の絵コンテ、そして詩のテキストの重ね表示（任意）を加えたもの
  （歌 + 絵コンテ画像 + ffmpeg の組み立てで、全部で約 $0.35）。MP4
  として here.now に公開し、リンクをチャットで送ります。実行の前に費用を
  確認してください。

エージェントはどれを作る前にもガイドを読み、学ぶ人の伝統で枝分かれし、
学ぶ人のプロファイルに合わせます。カリキュラムスキルと同じルールです。

### 8：メンテナンス

ときどき行うもの：

- `hermes update`：標準の Hermes スキルライブラリをプロファイルに
  取り込みます（キュレーションされたスキルが上書きされることは
  ありません）。
- `git -C ~/.hermes/profiles/onetoeight-agent pull`：ガイドやスキルの
  上流の改善を取ってきます。
- `cronjob(action="list")`：ジョブがまだ予定に入っているか確認します。

## `.env` で設定するもの

プロファイルには `.env.example` が付いていて、すべての変数が書かれて
います。実際に設定するのは、こちらです。

### 必須（どのセットアップでも）

```bash
# Model provider key
OPENAI_API_KEY=...          # or your provider's key name

# Web search (free)
JINA_API_KEY=jina_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### Telegram 配信に必須

```bash
# Get these from @BotFather in Telegram
TELEGRAM_BOT_TOKEN=1234567890:ABCDefghijklmnopqrstuvwxyz
TELEGRAM_CHAT_ID=123456789
```

> **Telegram セットアップのメモ：** @BotFather で bot を作ったあと、
> エージェントが送れるようになる前に、**bot へ少なくとも1通メッセージを
> 送る必要があります**（たとえば `/start`）。一度もメッセージを
> 受け取っていない bot は、送信のときに静かに失敗します。

chat ID を調べるには：Telegram で `@userinfobot` にメッセージを送ると、
数字の ID を返してくれます。

### 音声（朝の1分）に必須

```bash
# here.now is a site publisher, not a drive. The API key is all you need.
# DRIVE_ID is not used by the audio publish flow — ignore it if you see it.
HERENOW_API_KEY=hn_xxxxxxx
```

> **here.now についてのメモ：** 音声は here.now の公開 API で
> アップロードされ、公開 URL が発行されます。この URL は multipart
> upload で Telegram に送られるので、DRIVE_ID は**必要ありません**。
> 古いドキュメントや例に `HERENOW_DRIVE_ID` があるかもしれませんが、
> それは以前のもので、今の音声配信の流れでは使いません。

### 任意の連携

```bash
# Notion
NOTION_API_KEY=...

# GitHub (for tracking, opening issues)
GITHUB_TOKEN=...

# Bluesky (if you publish there)
BLUESKY_HANDLE=...
BLUESKY_APP_PASSWORD=...
```

### 環境変数ではないもの

- **音声モデルのパス**：プロファイルのメモリーに保存され、環境変数では
  ありません。パスはパソコンごとに違います。
- **cron のスケジュール**：`cronjob(action="create", ...)` で設定し、
  cron レジストリに保存されます。環境変数ではありません。
- **Piper の実行ファイルのパス**：プロファイルのメモリーに保存されます。
- **Mnemosyne**：ローカル優先で、キーは不要です。

## 設定リファレンス

### モデルプロバイダー（`config.yaml`）

```yaml
model:
  default: deepseek-v4-flash
  provider: openrouter
fallback_providers:
  - provider: opencode
    model: deepseek-v4-flash
```

`provider` と `default` を変えれば切り替えられます。デフォルトが
OpenRouter なのは、キー1つで一番広いカタログが開けるからです。無料の
モデルに加えて、マルチモーダル（画像、音声）のモデルも、プロバイダーを
変えずに使えます。フォールバックの連鎖は、メインのプロバイダーが
使えないときにだけ動きます。

### ツールセット（`config.yaml`）

CLI のツールセットは、**すべてデフォルトで有効**です。オリエンテーション
で、学ぶ人が1つずつ確認します。手動で無効にするには：

```bash
hermes --profile onetoeight-agent tools
# Or start with a specific set:
hermes --profile onetoeight-agent chat --toolsets "web,terminal,file,memory"
```

朝の1分のためには、`tts` ツールセットをオンのままにしてください。

### cron ジョブ

作成はオリエンテーションから行います。手動で管理するには：

```python
# List
cronjob(action="list")

# Create Morning Minute (UTC schedule — 6am AEST = 20:00 UTC)
cronjob(
    action="create",
    schedule="0 20 * * *",
    name="Morning Minute",
    prompt="""You are running the student's Morning Minute.
    Use the morning-minute skill. The student's tradition is
    <christian/universal>. Generate the day's plan, run Piper TTS,
    upload to here.now, deliver via multipart upload to Telegram.
    Do not write memories. Deliver only the final voice + text.""",
    skills=["morning-minute"],
    deliver="telegram",
)

# Weekdays only Morning Minute (6am, Mon–Fri)
cronjob(
    action="create",
    schedule="0 20 * * 1-5",
    name="Morning Minute",
    ...
)

# Pause without deleting
cronjob(action="pause", job_id="<id>")

# Resume
cronjob(action="resume", job_id="<id>")

# Remove (requires approval — deletes the schedule permanently)
cronjob(action="remove", job_id="<id>")
```

朝の1分の cron の契約の全文は、`skills/hermes/morning-minute/SKILL.md`
を見てください。

> **cron の配信：** TUI/CLI のセッションには、その場で届けるチャンネルが
> ありません。cron が起動したときに通知がほしいときは、作成のときに
> `deliver="telegram"`（または `deliver="all"`）を設定してください。
> そうしなければ、出力はローカルに保存され、`cronjob(action="list")` で
> 見られます。

## よくあるつまずき

| 症状 | よくある原因 | 直し方 |
|---|---|---|
| Piper が読み込めない | 音声モデルのパスが違うか、まだダウンロードしていない | オリエンテーションの Piper のステップをもう一度実行する |
| 朝の1分の音声が無音、または途中で切れる | TTS に入れるテキストが途中で切れていた | 音声合成の前に、テキストファイルが完全か確認する |
| Telegram の送信が "chat not found" で失敗する | bot がまだ一度もメッセージを受け取っていない | Telegram を開き、自分の bot を見つけて `/start` を送る |
| Telegram で音声が再生されない | here.now の URL を `MEDIA:<url>` で使っている | `sendVoice` の multipart upload を使う（スキルが処理します） |
| cron が間違った時刻に起動する | UTC の混同 | cron は UTC で保存します。日本時間の朝6時 = `0 21 * * *`。シドニーの朝6時 = `0 20 * * *` |
| 毎日の設定なのに平日しか起動しない | cron の書式が違う | `0 6 * * *` = 毎日。`0 6 * * 1-5` = 月〜金 |
| Jina の検索が何も返さない | `.env` にキーがない、または間違っている | `curl -H "Authorization: Bearer ***" "https://s.jina.ai/"` で試す |
| エージェントが違う伝統の内容を出す | メモリーに伝統が入っていない | オリエンテーションの伝統のステップをもう一度実行する |
| レッスンのファイルが読まれない | `.christian.md` か `.universal.md` の接尾辞が足りない | `ls essentials/<NN>/lessons/` を確認してください。ファイル名の接尾辞が正しい必要があります |

## Token Router プラグイン（任意）

Token Router は任意の Hermes プラグインで、エージェントに見える
**ツールの範囲を絞ります**。学ぶ人に対してではありません。有効にすると、
エージェントがデフォルトで見るツールが減り、token の使用量を抑えて、
8つのエッセンシャルの仕事に集中しやすくなります。

学ぶ人から機能を隠すことは**ありません**。学ぶ人はこれまでどおり何でも
頼めます。router が影響するのは、エージェントが自動で選ぶときの候補
だけです。

次の場合は有効にしてください：
- エージェントを、コードやデータ分析ではなく、教えることに集中させたい。
- token の使用量が気になる。

次の場合はオフのままにしてください：
- 学ぶ人（または保護者）が、ツールのすべてを使いたい。

有効にするには：`hermes plugins enable hermes-token-router`
（`hermes profile use onetoeight-agent` のあとに）。
