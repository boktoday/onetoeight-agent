# OneToEight Agent: ภาพรวมและขั้นตอนการตั้งค่า

**OneToEight Agent** คือผู้ช่วย AI ส่วนตัวที่สร้างอยู่บน [Hermes Agent](https://hermes-agent.nousresearch.com/docs) สำหรับคนรุ่นใหม่ที่กำลังเรียนรู้ที่จะนำ **แปดสิ่งจำเป็น** ไปใช้ในชีวิตประจำวัน เป็นพี่เลี้ยงที่อ่อนโยนซึ่งดูแลจังหวะชีวิตประจำวัน ทั้งแผนเสียง เช็กอินทบทวนตัวเอง และก้าวเล็ก ๆ ที่สอนจากคู่มือแปดสิ่งจำเป็นที่มาพร้อมกับ repo

README นี้คือภาพรวมและขั้นตอนการทำให้ agent ทำงานได้ครบวงจร อ่านสักครั้ง แล้วค่อยไล่ทำตามขั้นตอน

> **สองวิธีในการเริ่มต้น.** ไปตาม **build path** แล้วประกอบ agent ทีละชิ้น: หนึ่งความสามารถ หนึ่งผลที่เห็นได้ ทุกสัปดาห์ พร้อมเสียงให้ฟังตาม หรือจะติดตั้งด้วยขั้นตอนการตั้งค่าด้านล่างก็ได้
>
> **เริ่ม build path: <https://gladtobe.here.now/build-path/>**

## ผลิตภัณฑ์นี้คืออะไร

คนรุ่นใหม่เรียนรู้แปดสิ่งจำเป็นได้ดีที่สุดด้วย**การลงมือทำสิ่งเล็ก ๆ หนึ่งอย่างต่อวัน** สะสมเป็นสัปดาห์เป็นเดือน ไม่ใช่ด้วยการอ่านหนังสือ OneToEight Agent มีอยู่เพื่อทำให้จังหวะประจำวันนั้นติดอยู่จริง:

- **นาทีเช้า** (Morning Minute) มาถึงตามเวลาที่ผู้เรียนเลือก ในแชตของผู้เรียน (Telegram หรือ WhatsApp) เป็นแผนเสียงสั้น ๆ สำหรับวันนั้น พร้อมข้อความ
- **เช็กอินตอนบ่าย** (Afternoon Check-In) มาถึงในตอนบ่าย เป็นข้อความสั้น ๆ: วันนี้เป็นอย่างไร อะไรคือสิ่งต่อไป หนึ่งคำถามให้เก็บไปคิดตอนนอน
- **ช่วงวางแผน** (Planning Session) มาถึงก่อนนอน มันวางแผนพรุ่งนี้ให้: งานที่โรงเรียน กำหนดส่งการบ้าน สิ่งจำเป็นที่กำลังทำอยู่สัปดาห์นี้ และหนึ่งอย่างจริง ๆ ที่อยากลงมือทำในโลกจริง agent ร่างแผน ผู้เรียนแก้ไข และบันทึกไว้ในเครื่อง ไม่มีแอป ไม่มีบัญชี ไม่มี cloud sync
- agent สอนจาก**คู่มือแปดสิ่งจำเป็น**ที่เก็บอยู่ใน repo (`essentials/01..08/lessons/*.md`) โดยแยกตามธรรมเนียมที่ผู้เรียนเลือก
- คู่มือนี้ยังเผยแพร่ใน**สิบภาษา** อ่านออนไลน์ หรือดาวน์โหลดเป็นชุดออฟไลน์ไว้ใช้แบบไม่มีอินเทอร์เน็ต ดู `essentials/guide-editions.md`

agent ไม่เทศนา มันดึงปัญญาออกจากผู้เรียนด้วยคำถาม ประคองจังหวะอย่างอ่อนโยน และช่วยให้เริ่มใหม่เมื่อหลุด โดยไม่ดุว่า

### สองธรรมเนียม หรือธรรมเนียมของคุณเอง

ทุกคนเลือกหนึ่งอย่างตอน onboarding หรือบอก agent ว่าธรรมเนียมของคุณคืออะไร แล้วมันจะสร้างให้ agent อยู่ในธรรมเนียมที่เลือกเสมอ ไม่เคยผสมธรรมเนียมเข้าด้วยกัน:

- **คริสเตียน** -- ยึดพระคัมภีร์เป็นหลัก นาทีเช้ามีข้อพระคัมภีร์หนึ่งข้อทุกเช้า อ่านอย่างเป็นธรรมชาติ เช็กอินวางกรอบของวันไว้ในความเชื่อที่มีชีวิต
- **Universal (แบบไม่ยึดศาสนา)** -- ให้เกียรติธรรมเนียมแห่งปัญญาโดยไม่มีหลักคำสอน นาทีเช้ามีข้อใคร่ครวญสั้น ๆ หรือคำถามจากนักคิดคนหนึ่ง เช็กอินวางกรอบของวันไว้ในความใคร่ครวญ ความขอบคุณ และความตั้งใจ

ผู้เรียนเปลี่ยนธรรมเนียมทีหลังได้ แต่บทเรียนจะแยกสาขาจากจุดนั้นเป็นต้นไป

### สองลำดับการส่ง

ผู้เรียนแต่ละคนเลือกด้วยว่าแปดสิ่งจำเป็นจะถูกส่งแบบไหน:

- **เรียงตามลำดับ** (ค่าเริ่มต้น) -- เดินผ่านสิ่งจำเป็นข้อ 1 ถึง 8 ตามลำดับ วิธีนี้เชื่อมโยงกันมากที่สุดและเป็นลำดับที่คู่มือเขียนไว้ แนะนำสำหรับผู้เรียนใหม่
- **สุ่ม** -- หยิบสิ่งจำเป็นข้อไหนก็ได้ในแต่ละวัน ให้เข้ากับสิ่งที่ผู้เรียนดูเหมือนต้องการในวันนั้น (ข้อที่เว้นว่างนานสุด ความยากที่เพิ่งเจอ พลังงานของวันนั้น) นาทีเช้าทุกครั้งเปิดด้วยสรุปความรู้จากสิ่งจำเป็นที่เลือก บวกกิจกรรมเล็ก ๆ หนึ่งอย่าง เหมาะกับผู้เรียนที่รู้อยู่แล้วว่าตัวเองต้องการอะไร

ทั้งสองแบบ **ครอบคลุมแปดสิ่งจำเป็นครบทุกข้อในที่สุด** ผู้เรียนสลับได้ทีหลังด้วยการอัปเดตคีย์ memory `essentials_order` ไม่ต้อง onboarding ใหม่

### แปดสิ่งจำเป็น (ตามลำดับที่คู่มือสอน)

1. **ความเงียบ** -- นั่งนิ่ง ๆ อยู่กับความคิดของตัวเอง
2. **ร่างกาย** -- การนอน อาหาร น้ำ การเคลื่อนไหว แสงแดด
3. **ทักษะ** -- ความสามารถจริงที่ใช้ได้ในชีวิต (ทำอาหาร ซ่อมของ สร้างของ วางงบ)
4. **การป้องกันตัวในโลกดิจิทัล** -- ความเป็นส่วนตัว ความสนใจ การรู้เท่าทันตัวตน
5. **ชุมชนที่แท้จริง** -- ผู้คนที่รู้จักชื่อของคุณ
6. **ความรู้ที่ไม่ต้องมี Wi-Fi** -- เป็นเจ้าของ ไม่ใช่เช่า
7. **ธรรมชาติ** -- เวลาข้างนอกแบบกำหนดไว้ ไม่ต่อรอง
8. **ความเชื่อที่ผ่านการทดสอบ** -- ของคุณ และยืนหยัดได้ภายใต้แรงกดดัน

## มันทำงานอย่างไร

### วงจรประจำวัน

```
06:00  นาทีเช้า          เสียง Piper + ข้อความ → Telegram หรือ WhatsApp
        ↓
กลางวัน  ผู้เรียนลงมือทำสิ่งเล็ก ๆ หนึ่งอย่าง
        ↓
17:00  เช็กอินตอนบ่าย    ข้อความเท่านั้น → Telegram หรือ WhatsApp
        ↓
21:00  ช่วงวางแผน         ข้อความเท่านั้น → Telegram หรือ WhatsApp
       agent ร่างแผนของพรุ่งนี้ → ผู้เรียนแก้ไข → บันทึกไว้ในเครื่อง
        ↓
        นอน
        ↓
        ทำซ้ำ
```

agent ตอกย้ำวงจรนี้โดยไม่เซ้าซี้ วันที่พลาดไปเริ่มใหม่อย่างเบามือ ไม่ดุว่า ไม่เทศนา

**เกี่ยวกับตารางเวลา:** เวลาข้างบนเป็นเวลาท้องถิ่นของผู้เรียน cron daemon เก็บตารางเป็น **UTC** ถ้าคุณเลือก 6 โมงเช้าตามเวลาไทย (UTC+7) cron จะเก็บเป็น `0 23 * * *` (23:00 UTC) ตารางนี้คือ "เวลาตาม timezone ของคุณ" เสมอ การแปลงเป็น UTC เกิดขึ้นอัตโนมัติ

### งานของ agent ในแต่ละช่วง

| เมื่อ | agent ทำอะไร |
|---|---|
| แชตแรกบนโปรไฟล์ใหม่ | เสนอการปฐมนิเทศสั้น ๆ ด้วยเสียงของตัวเอง |
| ผู้เรียนพิมพ์ว่า "ตั้งค่าให้หน่อย" | รัน `agent-onboarding` (ต้องยินยอมก่อน แบ่งเป็นช่วง) |
| ผู้เรียนถามคำถาม | อ่าน `essentials/<NN-name>/lessons/*.md` ที่เกี่ยวข้อง สังเคราะห์ แล้วสอน |
| cron นาทีเช้าทำงาน | สร้างแผนของวันนั้น รัน Piper อัปโหลด แล้วส่งเข้าแชตโดยตรง |
| cron เช็กอินทำงาน | อ่านนาทีเช้าล่าสุด ร่างบทใคร่ครวญสั้น ๆ ส่งเป็นข้อความ |
| cron ช่วงวางแผนทำงาน | ร่างแผนของพรุ่งนี้ (งานโรงเรียน กำหนดส่งการบ้าน สิ่งจำเป็นของสัปดาห์ หนึ่งอย่างจริง ๆ) ผู้เรียนแก้ไข บันทึกไว้ในเครื่อง |
| ผู้เรียนขอเจาะลึก | ใช้สกิล `eight-essentials-curriculum` อ่านคู่มือ แล้วสอนจากคู่มือ |

### สิ่งที่ทำงานอยู่เบื้องหลัง

cron job สามตัว ทั้งหมดปิดอยู่จนกว่าผู้เรียนจะอนุมัติตอน onboarding:

1. **นาทีเช้า** -- ทำงานตามเวลาที่เลือกใน timezone ของผู้เรียน ทุกวัน (หรือเฉพาะวันธรรมดา ถ้าอยากอย่างนั้น) สร้างเสียง + ข้อความ และส่งไปยัง Telegram หรือ WhatsApp
2. **เช็กอินตอนบ่าย** -- ทำงานตามเวลาบ่ายที่เลือก ใช้กฎเรื่องวันเดียวกับนาทีเช้า ส่งข้อความสั้น ๆ
3. **ช่วงวางแผน** -- ทำงานก่อนนอน (ค่าเริ่มต้น 21:00) ใช้กฎเรื่องวันเดียวกัน ร่างแผนของพรุ่งนี้ให้ผู้เรียนแก้ไข แล้วบันทึกไว้ในเครื่อง

ทั้งสามแบบเป็น **opt-in** -- การปฐมนิเทศจะสร้างให้หลังได้รับความยินยอมชัดเจนเท่านั้น

### ยี่สิบคำถามประจำวัน

คลังเล็ก ๆ ของคำถามติดมือที่คนรุ่นใหม่ยื่นให้ OneToEight Agent ได้ทุกเมื่อ agent อ่านบทคู่มือที่เกี่ยวข้อง ดึงสิ่งที่มันรู้อยู่แล้วเกี่ยวกับผู้เรียน และตอบในน้ำเสียงของผู้เรียน ตามธรรมเนียมของผู้เรียน

จุดสำคัญ **ไม่ใช่**การตอบทั้งยี่สิบข้อทุกวัน จุดสำคัญคือการมีชุดคำถามติดมือเล็ก ๆ ที่ชูสิ่งจำเป็นขึ้นมา ดึงความใคร่ครวญออกมา และเปลี่ยนความอยากรู้อยากเห็นให้กลายเป็นกิจวัตรประจำวัน เลือกสักหนึ่งหรือสองข้อ ข้ามที่เหลือ แล้วเวียนสลับไปทั้งสัปดาห์

คำถามเขียนด้วยน้ำเสียงของคนรุ่นใหม่ agent ไม่เทศนากลับ มันถามคำถาม เปิดที่ว่างให้คำตอบ และต่อด้วยการลงมือเล็ก ๆ หนึ่งอย่าง

ไฟล์คำถามฉบับเต็มอยู่ที่ `essentials/00-introduction/lessons/prompts.md` agent จะอ่านไฟล์นี้เมื่อผู้เรียนขอ "อะไรที่ชวนคิด" ขอคำถามให้เก็บไปคิด หรือขอความช่วยเหลือตอนตัน

#### agent ใช้คำถามเหล่านี้ยังไง

agent อ่าน `essentials/00-introduction/lessons/prompts.md` ทุกครั้งที่ผู้เรียนขอคำถาม มันจะ **ไม่** แปะคำถามใส่ผู้เรียน มันอ้างถึงคำถามหนึ่งข้อ ชวนผู้เรียนให้อ่าน และเปิดที่ว่างให้คำตอบ มันไม่ถามสามข้อติดกัน

ในลำดับแบบ **เรียงตามลำดับ** คำถามจะเกาะกลุ่มอยู่รอบ ๆ สิ่งจำเป็นที่ผู้เรียนกำลังทำอยู่ตามธรรมชาติ ในแบบ **สุ่ม** agent เลือกคำถามที่เข้ากับจังหวะนั้น แปดสิ่งจำเป็นทั้งหมดยังใช้ได้ครบในทั้งสองแบบ

**หนึ่งวัน.** นาทีเช้าเปิดวัน เช็กอินปิดวัน และช่วงวางแผนวางแผนพรุ่งนี้ก่อนนอน สามรูปแบบที่ขอได้เมื่อต้องการ (สรุป / บทเรียน / บทกวี) พร้อมอยู่เสมอเมื่อคนรุ่นใหม่อยากเรียนสิ่งจำเป็นข้อหนึ่งให้ลึกกว่าที่นาทีเช้าจะครอบคลุมได้ในหนึ่งนาที

**โค้ดอยู่ตรงไหน.** แต่ละแถวลิงก์ไปยังสกิลใน repo:

| กิจวัตร | พาธของสกิล |
|---|---|

**ความยินยอม.** สามกิจวัตรแบบ cron (นาทีเช้า เช็กอิน ช่วงวางแผน) ปิดอยู่จนกว่าผู้เรียนหรือผู้ปกครองจะอนุมัติตอน onboarding ห้ารูปแบบที่ขอได้เมื่อต้องการ (สรุป บทเรียน บทกวี เพลง มิวสิกวิดีโอ) ใช้ได้ทันที ผู้เรียนแค่ขอ สองรูปแบบที่มีค่าใช้จ่าย (เพลงและมิวสิกวิดีโอ, Lyria 3 + ภาพสตอรีบอร์ด) ต้องให้ผู้เรียนยืนยันค่าใช้จ่ายทุกครั้งที่ขอ ดู [ขั้นตอนการตั้งค่า → สิ่งที่ทำงานอยู่เบื้องหลัง](#สิ่งที่ทำงานอยู่เบื้องหลัง) สำหรับลำดับ opt-in ที่แน่นอน

**สกิลของเพลงและมิวสิกวิดีโอ.** สองรูปแบบที่มีค่าใช้จ่ายใช้สกิลเดิมสองตัวซ้ำ ไม่ได้ประดิษฐ์ใหม่:

## ทูทอเรียล

อยากได้ไกด์ที่พาเดินทีละขั้นไหม? ศูนย์รวมทูทอเรียลรวบหน้าตั้งค่าทั้งหมดไว้ในที่เดียว:

- **build path** -- เจ็ดหน้าที่สอนผ่านการลงมือสร้าง: ประกอบ agent ทีละชิ้น พร้อมเสียงให้ฟังตาม เริ่มที่ <https://gladtobe.here.now/build-path/>.

### 4: การปฐมนิเทศ (ต้องยินยอมก่อน)

การปฐมนิเทศเป็นบทสนทนา agent จะถามคำถามที่เกี่ยวเนื่องกันเป็นกลุ่มเล็ก ๆ ครั้งละกลุ่ม และ**หยุดที่จุดขอข้อมูลรับรองทุกจุด** มันไม่ขอคีย์หรือโทเคนในแชตเลย

นี่คือสิ่งที่ครอบคลุม เรียงตามลำดับ:

| ขั้น | เกิดอะไรขึ้น | เพิ่มตรงไหน |
|---|---|---|
| 1. ตัวตน | ชื่อ (ของคุณ ของผู้เรียน ของ agent) สไตล์การตอบ และภาษาสำหรับคู่มือ บทเรียน และข้อความ | เก็บไว้ใน memory ของโปรไฟล์ |
| 2. โปรไฟล์และชีวิต | อายุ ที่อยู่ สถานการณ์ที่พัก รูปแบบของสัปดาห์ ความสนใจ 3 อย่าง เป้าหมายโฟกัส วงเพื่อน อุปสรรค หัวข้อห้ามแตะ -- ฟิลด์ที่ agent ใช้ปรับแต่งนาทีเช้าและบทเรียน | เก็บไว้ใน memory ของโปรไฟล์ |
| 3. ธรรมเนียม | คริสเตียน Universal หรือธรรมเนียมของตัวเอง | เก็บไว้ใน memory ของโปรไฟล์ |
| 4. ติดตั้ง Piper + เสียง | ตรวจว่า Piper ทำงานได้ เลือกเสียง ดาวน์โหลดโมเดลเสียง | โมเดลเสียงใน `piper-voices/` |
| 5. คีย์ Jina API | สมัครฟรี เพิ่มใน `.env` agent ตรวจสอบด้วยการค้นหาจริง | `JINA_API_KEY=` ใน `.env` |
| 6. ช่องทางส่ง | ข้อมูลบอท Telegram หรือ WhatsApp | `TELEGRAM_BOT_TOKEN=` / `WHATSAPP_*` ใน `.env` |
| 7. คู่มือแปดสิ่งจำเป็น | ยืนยันว่าไฟล์บทเรียน MD อยู่ใน `essentials/01..08/lessons/` และแชร์ฉบับคู่มือในภาษาของผู้เรียน (`essentials/guide-editions.md`) | ไฟล์ใน repo |
| 8. Memory | แนะนำ Mnemosyne (เก็บในเครื่อง ไม่มีบัญชีภายนอก) | `hermes memory setup` |
| 9. ตารางนาทีเช้า | กี่โมง timezone ไหน วันไหน | สร้างเป็น cron job |
| 10. ตารางเช็กอินตอนบ่าย | กี่โมง timezone ไหน วันไหน | สร้างเป็น cron job |
| 11. ตารางช่วงวางแผน | กี่โมง (ค่าเริ่มต้น 21:00) timezone ไหน วันไหน | สร้างเป็น cron job |
| 12. Token Router (ไม่บังคับ) | ปลั๊กอินที่ย่อพื้นผิวเครื่องมือ | `plugins.enabled` ใน `config.yaml` |

ตอนท้าย agent จะแสดงสรุป **Proposed setup** และรอการอนุมัติที่ชัดเจนจากคุณก่อนจะลงมือทำอะไร

### 6: การทำงานตามตารางครั้งแรก

นาทีเช้าจะทำงานตามเวลาที่ตั้งไว้ครั้งถัดไปใน timezone ของผู้เรียน มันสร้างเสียง (Piper) อัปโหลดขึ้น here.now เพื่อได้ URL สาธารณะ แล้วส่งเสียงนั้นตรงเข้า Telegram ด้วย multipart upload -- **ไม่ใช่**ผ่านลิงก์ `MEDIA:<url>` (การตั้งค่า Cloudflare ของ here.now บล็อกบอทดึงไฟล์ของ Telegram) เช็กอินจะทำงานตามเวลาบ่ายที่ตั้งไว้ครั้งถัดไป

### 7: การใช้งานในแต่ละวัน

ผู้เรียนไม่ได้คุยกับ agent ผ่าน terminal ทุกวัน แชต Telegram หรือ WhatsApp **คือ**พื้นผิวการใช้งานประจำวัน:

- **นาทีเช้า** มาถึงเป็นข้อความเสียง + แผนแบบข้อความ
- **เช็กอินตอนบ่าย** มาถึงเป็นข้อความ
- **ช่วงวางแผน** มาถึงก่อนนอนเป็นข้อความ -- agent ร่างแผนของพรุ่งนี้ (งานโรงเรียน กำหนดส่งการบ้าน สิ่งจำเป็นของสัปดาห์ หนึ่งอย่างจริง ๆ) ผู้เรียนแก้ไข แล้วบันทึกไว้ในเครื่อง ดู `skills/profile/planning-session/`
- **ตอบเช็กอิน** ด้วยบันทึกสั้น ๆ หนึ่งบรรทัดว่าวันนี้เป็นอย่างไร agent จะบันทึกสรุปไว้และใช้เป็นจุดเชื่อมในนาทีเช้าของพรุ่งนี้
- **ถามคำถามได้ทุกเมื่อ** "ความเชื่อที่ผ่านการทดสอบจริง ๆ หน้าตาเป็นยังไง?" "ผมจะหาชุมชนที่แท้จริงได้ยังไง?" agent จะอ่านคู่มือแล้วสอน

#### วิธีเรียนรู้สิ่งจำเป็นให้ลึกขึ้น (เมื่อขอ)

นอกเหนือจากจังหวะประจำวัน ผู้เรียนขอ**สามรูปแบบที่ลึกกว่า**ในสิ่งจำเป็นข้อไหนก็ได้ ทั้งสามดูแลโดยสกิล `essential-deep-dives` (ดู `skills/profile/essential-deep-dives/`) และทั้งสามไม่ต้องทำอะไรนอกจากขอ:

- **สรุปสิ่งจำเป็น** -- ประเด็นสำคัญของสิ่งจำเป็นหนึ่งข้อในภาษาง่าย ๆ บวก**ข้อความเสียง** 3 ถึง 5 นาทีที่ agent สร้าง (Piper) แล้วหย่อนลงในแชต ให้ผู้เรียนฟังตอนเดินหรือทำงานบ้าน
- **บทเรียนสิ่งจำเป็น** -- **บทเรียนสามหน้า**ที่สวยงาม สร้างเป็นหน้า HTML และเผยแพร่ขึ้นบัญชี **here.now** ของบ้าน สอนสิ่งจำเป็นนั้นด้วย**แหล่งอ้างอิงที่อ้างถึง** (ค้นผ่าน Jina API ทุกครั้งที่บทเรียนต้องการเนื้อหาที่คู่มือไม่มี) **คำพูดสำคัญ** และ**ควิซสั้น ๆ** ที่ผู้เรียนตอบเองบนหน้าเว็บ agent ส่งลิงก์ในแชต
- **บทกวีสิ่งจำเป็น** -- **บทกวีพูดเป็นจังหวะ**มีสัมผัสในสิ่งจำเป็นนั้น อ่านออกเสียงเป็นข้อความเสียง พร้อมข้อความด้านล่างให้อ่านตาม
- **เพลงสิ่งจำเป็น** -- agent เขียนบทกวีต้นฉบับเกี่ยวกับสิ่งจำเป็นนั้น แล้วเปลี่ยนเป็นเพลงจริง (MP3) ผ่าน `google/lyria-3-pro-preview` บน OpenRouter (~$0.08 ต่อเพลง) ข้อความเสียงเล่นในแชต ตามด้วยข้อความบทกวี ยืนยันค่าใช้จ่ายก่อนรัน
- **มิวสิกวิดีโอสิ่งจำเป็น** -- เพลงข้างบน บวกสตอรีบอร์ดของภาพนิ่งที่เย็บเข้ากับเสียง และข้อความบทกวีซ้อนทับได้ถ้าต้องการ (~$0.35 รวมทั้งหมด ทั้งเพลง ภาพสตอรีบอร์ด และการประกอบด้วย ffmpeg) เผยแพร่เป็น MP4 ขึ้น here.now แล้วส่งลิงก์ในแชต ยืนยันค่าใช้จ่ายก่อนรัน

agent อ่านคู่มือก่อนร่างสิ่งเหล่านี้ทุกครั้ง แยกตามธรรมเนียมของผู้เรียน และปรับให้เข้ากับโปรไฟล์ผู้เรียน ใช้กฎเดียวกับสกิลหลักสูตร

### 8: การดูแลรักษา

วิธีดู chat ID ของคุณ: ส่งข้อความหา `@userinfobot` ใน Telegram แล้วมันจะตอบเลข ID ของคุณกลับมา

```bash

HERENOW_API_KEY=hn_xxxxxxx
```

> **หมายเหตุเรื่อง here.now:** เสียงถูกอัปโหลดผ่าน publish API ของ here.now ซึ่งให้ URL สาธารณะ URL นั้นถูกส่งต่อให้ Telegram ผ่าน multipart upload จึง**ไม่ต้องใช้** DRIVE_ID ถ้าคุณเห็น `HERENOW_DRIVE_ID` ในเอกสารหรือตัวอย่างเก่า ๆ นั่นคือของเดิมและไม่ถูกใช้ในขั้นตอนส่งเสียงปัจจุบัน

## เอกสารอ้างอิงการตั้งค่า

### ผู้ให้บริการโมเดล (`config.yaml`)

```yaml
model:
  default: deepseek-v4-flash
  provider: openrouter
fallback_providers:
  - provider: opencode
    model: deepseek-v4-flash
```

เปลี่ยน `provider` และ `default` เพื่อสลับผู้ให้บริการ ค่าเริ่มต้นคือ OpenRouter เพราะคีย์เดียวเปิดแคตตาล็อกที่กว้างที่สุด ทั้งโมเดลระดับฟรีและโมเดลหลายรูปแบบ (ภาพ เสียง) โดยไม่ต้องเปลี่ยนผู้ให้บริการ ห่วงโซ่สำรองจะทำงานเฉพาะเมื่อตัวหลักใช้งานไม่ได้

### Toolsets (`config.yaml`)

ทุก CLI toolset **เปิดใช้เป็นค่าเริ่มต้น** การปฐมนิเทศจะพาผู้เรียนทบทวนทีละตัว ถ้าอยากปิดเอง:

```bash
hermes --profile onetoeight-agent tools
# Or start with a specific set:
hermes --profile onetoeight-agent chat --toolsets "web,terminal,file,memory"
```

toolset `tts` ต้องเปิดอยู่เสมอสำหรับนาทีเช้า

### งาน cron

สร้างผ่านการปฐมนิเทศ จัดการเองได้แบบนี้:

```python
# List
cronjob(action="list")

# Create Morning Minute (UTC schedule — 6am AEST = 20:00 UTC)
cronjob(
    action="create",
    schedule="0 20 * * *",
    name="Morning Minute",
    prompt="""You are running the student's Morning Minute.
    Use the morning-minute skill. The student's tradition is
    <christian/universal>. Generate the day's plan, run Piper TTS,
    upload to here.now, deliver via multipart upload to Telegram.
    Do not write memories. Deliver only the final voice + text.""",
    skills=["morning-minute"],
    deliver="telegram",
)

# Weekdays only Morning Minute (6am, Mon–Fri)
cronjob(
    action="create",
    schedule="0 20 * * 1-5",
    name="Morning Minute",
    ...
)

# Pause without deleting
cronjob(action="pause", job_id="<id>")

# Resume
cronjob(action="resume", job_id="<id>")

# Remove (requires approval — deletes the schedule permanently)
cronjob(action="remove", job_id="<id>")
```

ดูสัญญา cron ฉบับเต็มของนาทีเช้าที่ `skills/hermes/morning-minute/SKILL.md`

> **Cron delivery:** เซสชัน TUI/CLI ไม่มีช่องทางส่งสด ถ้าอยากได้รับการแจ้งเตือนเมื่อ cron ทำงาน ให้ตั้ง `deliver="telegram"` (หรือ `deliver="all"`) ตอนสร้าง ไม่งั้นผลลัพธ์จะถูกบันทึกไว้ในเครื่องและดูได้ผ่าน `cronjob(action="list")`

## ปลั๊กอิน Token Router (ตัวเลือกเสริม)

Token Router เป็นปลั๊กอิน Hermes แบบเลือกใช้ได้ ที่**ย่อพื้นผิวเครื่องมือ**ที่ agent มองเห็น ไม่ใช่ที่ผู้เรียนเห็น เมื่อเปิดใช้ agent จะเห็นเครื่องมือน้อยลงเป็นค่าเริ่มต้น ซึ่งช่วยลดการใช้ token และทำให้ agent จดจ่อกับงานแปดสิ่งจำเป็น

มัน**ไม่**ซ่อนฟีเจอร์จากผู้เรียน ผู้เรียนยังถามอะไรก็ได้ router แค่มีผลกับสิ่งที่ agent เลือกใช้เองโดยอัตโนมัติ

เปิดใช้ถ้า:
- อยากให้ agent จดจ่อกับการสอน ไม่ใช่โค้ดหรือวิเคราะห์ข้อมูล
- กังวลเรื่องการใช้ token

ปิดไว้ถ้า:
- ผู้เรียน (หรือผู้ปกครอง) อยากให้มีเครื่องมือให้ใช้ครบทั้งหมด

วิธีเปิด: `hermes plugins enable hermes-token-router` (หลัง `hermes profile use onetoeight-agent`)
